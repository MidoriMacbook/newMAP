## Зеленая карта Липецкой области

Интерактивный путеводитель по заповедникам, памятникам природы, усадьбам и духовным центрам региона.
Сайт объединяет на одной карте 33 ключевые достопримечательности с подробными описаниями, фильтрацией и поиском.

### Зачем этот проект?

Информация о природных и культурных объектах Липецкой области разрознена. Мы создали единую платформу, где можно:

· Увидеть все значимые места на интерактивной карте
· Получить краткую и полную информацию о каждом объекте
· Фильтровать по типу (заповедники, усадьбы, монастыри и др.)
· Пользоваться с любого устройства - от ПК до смартфона

# Стек

HTML, CSS, JavaScript, Leaflet, OpenStreetMap, GitHub Pages

## Структура

```
newMAP/
├── index.html                 # Главная с картой
├── about.html                 # О проекте
├── all-sites.html             # Каталог
├── style.css                  # Стили
├── script.js                  # Основная логика
├── sites-data.js              # База данных (33 объекта)
├── CNAME                      # Домен
├── img/                       # Галерея сайта
├── images/                    # Фавиконы
└── sites/                     # Страницы ООПТ
    └── ... (всего 33 файла)
```

